# Аэроплат — автомобильные перевозки по России

Сайт: https://blackraydev.github.io/

Статический HTML/CSS/JS, локальные изображения и шрифты.
GitHub Pages публикует ветку `main` из корня репозитория; `.nojekyll` отключает обработку Jekyll.

Форма отправляет заявки на публичный сервер:
`https://aeroplat-road.black2001ray.chatgpt.site/api/requests`.
Данные сохраняются в Sites D1. API не предоставляет чтение заявок.
CORS разрешает этот GitHub Pages origin. Почтовая интеграция подготовлена;
она включается на сервере после настройки реальных адресов и Resend.
Контакты на сайте временные: +7 (999) 123-45-67, test@mail.ru.

Исходный проект хранится отдельно в `aeroplat` и в репозитории Sites.
Обновление: выполнить `npm run build:pages` в исходном проекте, перенести
содержимое `.sites-runtime/pages/` сюда, проверить и закоммитить в `main`.
Секреты и база данных в этот репозиторий не включаются.

Обновление 03.10.2026: на десктопе используется навигация в строку, на
мобильных устройствах — отдельный слой меню. Блоки появляются при прокрутке;
настройка уменьшения движения учитывается, весь контент доступен без JavaScript.

SEO: статический HTML, canonical на GitHub Pages, социальные метаданные,
Organization/WebSite/WebPage/Service JSON-LD, sitemap.xml, robots.txt и настоящая
страница 404. Тестовые телефон и email не включены в структурированные данные.
CSS и JavaScript минифицированы, ресурсы получают имена с хешем содержимого.
Старые ресурсы пока сохранены для совместимости с ранее кешированным HTML.
GitHub Pages кеширует HTML до 10 минут; уже открытую страницу нужно обновить.
